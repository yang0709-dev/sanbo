# Configurations
  
## File Structure
`./aesthetics.md` --> looks and feels  
`./settings.md` --> keybindings, directories that will be scanned  
  
## Getting Started
The config file is located at `~/.config/sanbo/<TheName>.json`
The configuration will be a big hashmap, something like this:
```json
{
  "background":"(10,10,10,1)",
  "foreground":(200,200,200,1)
}
  
Remember the last item(in this case foreground), must not add a trailing comma
